# 挟 — in a pinch

2人で同じ画面を使って指す盤上ゲーム。パソコンでもスマートフォンでも遊べます。

駒を取るゲームではありません。相手の駒を**挟んで封じ**、次の手を縛って詰ませます。

## 遊び方

手番でできることは2つだけです。

- **打つ** — 持ち駒を空きマスに置く
- **動かす** — 盤上の自分の駒を上下左右に動かす

動かした駒の隣にいる相手の駒が、その1つ先にある自分の駒か**盤の端**で挟まれると、
その駒は**封じられます**。封じられた側は、次の手番でその駒を動かさなければならず、
打つこともできません。

打って挟むことはできません。挟みは必ず移動で成立させます。

- 手番が来たときに封じ駒を動かせない、または打つ手も動かす手もなければ**負け**
- 自分の駒を上下左右に**4つつなげたら、その瞬間に負け**（斜めはつながっていません）
- 同じ局面が3回現れたら引き分け

盤の大きさ（5 / 7 / 9）、移動できる距離（1 / 2 / 3）、持ち駒の数（6 / 8 / 12）は
対局設定で変えられます。全文はアプリ内の「ルール」から読めます。

## 手元で動かす

```bash
npm install
npm run dev
```

http://localhost:5173 を開きます。

```bash
npm test    # ルールと対局進行のテスト
npm run build
```

## GitHub Pages へ出す

`main` に push すると `.github/workflows/pages.yml` がテストを通してから公開します。
初回だけリポジトリの設定が必要です。

1. Settings → Pages → Source を **GitHub Actions** にする
2. `main` に push する

公開先はリポジトリ名のサブパスになりますが、`vite.config.ts` が
`GITHUB_REPOSITORY` から自動で決めるので、リポジトリ名を書き換える必要はありません。

## 中身

```
src/
  core/   ルール。純粋関数だけで、DOM も通信も持たない
  app/    対局の進行。core と ui の仲介
  ui/     描画・入力・演出
  main.ts 組み立てのみ
```

依存は `ui → app → core` の一方向です。設計の決めごとは [CLAUDE.md](CLAUDE.md) にまとめてあります。

TypeScript + Vite（フレームワークなし）、テストは vitest。
盤面は DOM 要素と CSS transform で描いていて、Canvas は使っていません。
